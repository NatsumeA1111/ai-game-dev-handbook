# 新资源记录模板

复制下面的空记录，追加到 [查阅资源](resources.md)。这是记录格式，不是新的资源，也不是行业标准。没有实质新内容就不写。

沿用既有分级，不另造等级：

- 候选
- 文档核对
- 试用通过
- 不适用则标淘汰

热度不等于价值。评估保持与证据一致：只查过文档就写文档核对，未在项目试用不标推荐已验证，也不把文档核对改成试用通过。引擎版本或平台未知时写待确认。授权以各站点条款为准。每轮最多记 3 条。

## 空记录

- 资源：
- 类型：
- 评估：
- 采用结论：
- 来源链接：
- 核实日（Asia/Shanghai）：
- 引擎版本与平台：
- 是否已在项目试用：
- 授权：以各站点条款为准

填好后，若该条是基础查阅资源而不是 skill，类型写「基础资源，非 skill」，并同步补进 `resources.md` 的条目表与来源链接。优先方向仍是 Cocos 与 Codex、画风与素材、手感、音效、测试、构建。
