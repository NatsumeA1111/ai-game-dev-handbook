# 既有 UI 视口回归

状态：候选技能。来源为一次真实小屏修复及独立复查，见 [来源与边界](../../../knowledge/practice-evidence.md)。尚未做跨项目前向试用，不承诺自动通过。

读目标游戏 AGENTS.md 和项目档案；缺少主视口、入口或测试命令时先从工程核实，不猜引擎版本。只修用户指定界面，保留文案、玩法、候选和存档协议。

1. 固定复现输入，记录真实可见区域、缩放后 CSS 尺寸和逻辑尺寸。主视口与额外压力视口分开；文字 mock 测量只能做几何检查，不能证明真实 Label 排版。
2. 长内容用真实滚动容器和裁切区域；固定操作留在裁切区域外。按实际文字测量排版，不用省略正文或缩小字体掩盖溢出。遵循项目设计参数，不套用来源项目的像素值。
3. Resize 优先调整现有节点；检查不会重抽候选、重算报价、消费机会、推进模拟或触发存档交易。检查稳定尺寸重复更新不会把滚动位置反复归零。
4. 回归打开→选择→预览→确认，以及返回、取消、重开、连续点击、横竖切换。对长文和满格边界，滚到末行；从真实按钮中心双向拖动，检查滚动不误触按钮。合成鼠标不等于手机触摸。
5. 隔离 UI 夹具时同时控制宿主世界，避免其计时/自动保存重建 HUD 污染测量。夹具出错先修夹具，不能为了测试通过改生产逻辑。自然流程和注入边界分别报告。
6. 跑项目适用检查及实际引擎渲染，看截图像素与交互结果；代码检测器、类型检查、模拟几何不能替代画面验证。只关闭本次创建的测试进程。

输出使用 [验证记录](../../../templates/verification-record.md)：视口/输入矩阵、前后截图、状态不变量、失败重试、未测平台。若只验证竖屏状态保持，不能宣称竖屏可读性或真机验收。不能访问运行环境时交付静态结果和阻塞，不伪造截图。
