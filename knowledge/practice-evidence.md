核对日：2026-11-16。以下仅为用户授权提炼的通用方法，不发布源游戏代码、存档、截图、私人路径或账号。原始证据位于用户私有项目，公开读者无法独立复核；本次读取项目状态报告，未重新执行游戏测试，因此报告中的测试数量不作为本 PR 的测试结果。

## UI 视口

来源记录：既有 Cocos 游戏的小屏预览修复及独立验收报告。报告区分真实引擎渲染、模拟几何、合成鼠标和物理触摸；保留宿主世界自动保存污染隔离 UI 的失败。提炼成 [cocos-ui-viewport-check](../.agents/skills/cocos-ui-viewport-check/SKILL.md)，不带入原游戏数值或玩法。

## 存档

来源记录：浏览器持久化与严格事务两阶段报告。先前同步存储读回成功但进程终止后回滚，后续方案改以事务完成确认；仍不承诺断电或原生平台。提炼成 [cocos-save-regression](../.agents/skills/cocos-save-regression/SKILL.md)，不强推特定存储架构。

## 晋级条件

两项均标候选。已有项目实践不等于此技能文本已被独立 agent 正确使用。先在获授权的隔离任务中，仅给技能、项目档案和原始输入，由未读原对话的执行者完成；按 [证据模板](../templates/verification-record.md) 保存输出、失败与边界，之后才讨论“试用通过”。跨项目泛化要另留第二个项目证据。不要为凑技能数量填空壳。
