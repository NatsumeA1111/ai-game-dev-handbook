# 角色设计与单动作流水线

候选技能，非端到端已验证产线。先读目标游戏 AGENTS.md、当前视觉规范、[项目规范模板](../../../templates/character-motion-profile.md) 和 [实践边界](../../../knowledge/character-motion-evidence.md)。来源优先级遵循该项目，历史样稿不能覆盖最新用户决定。模板和技能不授予生成、上传、付费、安装或发布权限。

## 先静态设计，再确认母稿，再做动作

静态角色设计是动作的前置门槛：先根据项目视觉规范制作或审阅静态设计（制作仍需当前任务授权），在目标视角与游戏尺寸检查并提交用户确认母稿。静态母稿未经明确确认，不提交任何动作生成，也不把旧实验候选、单纯技术可用或动作实践授权当作母稿已确认。用户改为先做静态时，停止新增动作任务，已有任务按当前指令处理并如实报告；不要在后台继续抽动作。

## 确定设计与执行范围

- 区分角色身份母稿、视角规范、动作候选和正式素材。列出身份、轮廓、身体比例、武器几何、握持、服装、配色及不可改变项；以目标游戏尺寸确认可读性，不只看放大概念图。
- 固定镜头、朝向、全身留白和脚底参考。原画有弓梢与鞋相切、手部不清等缺陷时先登记，不把坏母帧当正式定稿；需要换母稿或美术方向时取得对应授权。
- 选择一个有明确用途和验收条件的动作。模型、服务和允许尝试次数从项目配置与本次授权读取；H3 是可选项目路线，不是所有游戏默认。指定 H3 only 的项目不得自行改 Wan 或其他模型。
- 记录是只写规范、查旧任务、后处理，还是允许新增生成。已有任务先查原 ID；连接中断、下载失败不等于需要重新提交。暂停中的动作不会因为读到技能而重启。

## 按证据推进

1. **执行预检**：核对服务已有模型、工作流及节点 schema，保存输入 hash、工作流、模型/编码器/VAE 标识、seed、分辨率、FPS、帧数及采样参数。没有必要权限或预算就停止提交。不要安装新模型、另开服务、清队列或打断其他任务。只查询授权服务，不在公开记录放私有地址或凭据。
2. **原片留存**：每次生成保留稳定动作 ID、尝试序号、服务任务 ID、脱敏请求/状态、原片/源帧及 hash。保存前移除 Authorization、API key、签名 URL 等秘密；不得把凭据写进工作流或公开产物。响应不确定时先核对原任务，不能重复 submit。后处理、重下载、裁剪不记成新生成，历史失败不清零。
3. **动作质检**：看完整连续播放及阶段联系表，近看手、武器和释放点；按动作类型适用性检查准备→发力/释放→回收是否成立（待机/行走检查对应循环与运动，不强套射箭释放阶段），记录明确源帧索引。抽样不能宣称逐帧检查。武器变形、握点漂移、烘焙光效或缺少释放/回收，不能靠技术执行成功通过。实际弹道与命中特效按项目职责由引擎驱动，不擅自烘焙进人物序列。
4. **透明处理**：保留原片与可逆派生。对细弓弦、发丝、半透明边、武器和服装颜色，在浅/深/棋盘背景检查断裂、残绿、色污染及轮廓闪烁。删除孤立碎片不等于修复附着光效或武器结构。区分普通后处理、局部修帧和需重新生成的原因，先报告而非无限重抽。
5. **共框与时序**：全部选用帧共享裁框、固定缩放和脚锚，保留源帧映射及时间。脚底量测与含武器/碎片的整体包围盒分开。不得用逐帧位移/缩放掩盖漂移，或倒放伪造回收；项目明确采用特殊处理时记录原因并单独验证。不照搬另一项目的像素尺寸、FPS 或图集上限。
6. **真实尺寸与引擎**：先看实际角色显示尺寸，再看放大诊断。在授权隔离入口中用真实 SpriteFrame 和项目动作时钟验证释放、结束、循环、朝向、暂停/恢复；按项目覆盖攻速、打断/取消、重复触发和状态切换。画面释放与逻辑事件不同步要记录，不能为适配视频改伤害、冷却或业务规则。检查图集加载、纹理上限及目标设备性能；RGBA 估算不是实测显存，桌面预览不是目标平台通过。
7. **交付与入库**：依 [素材库对接](../../../docs/asset-library-contract.md) 记录来源、模型许可、输入许可、包版本、依赖、meta/UUID、最小示例与消费记录。能生成不代表可商用，许可不明标未获发行许可，不自行授予授权。正式替换、发布和批量扩展分别按授权执行。

## 判定与停止

逐项用 [验证记录](../../../templates/verification-record.md) 记通过/失败/阻塞/未运行；总评区分执行成功、诊断可播放、视觉合格、目标平台通过、正式采用。明确拒收项出现时可做获授权的诊断，但不得当合格资产推进。达到尝试上限、模型不匹配、原任务状态不明或质量反复无改进时停提交，保存失败并给出下一步取舍。不换动作 ID 或重置目录绕过次数。

成本含生成、后处理、修帧、审阅和引擎验证；服务器耗时不等于独占 GPU 时间，未记录写未记录，没有合格动作时单件合格成本写不适用。只清理本次测试进程，不删原片、历史失败或用户数据。
